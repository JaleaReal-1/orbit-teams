INFORMACIÓN DE ESTA VERSIÓN

Cómo usamos tus datos.

Esta página explica el funcionamiento actual de la demo de Orbit Joy.

Lo que se guarda

Al crear un regalo, se guardan el nombre de quien lo crea, su WhatsApp, el método y estado de pago, el nombre de quien recibe, el mensaje, el modelo de carrito y la dirección de la foto si se añade. La demo actual usa una base SQLite en el servidor; las fotos se guardan en el disco del servidor.

Lo que se muestra en el regalo

La página del regalo muestra el nombre de quien recibe, el mensaje, el carrito y la foto opcional. La API pública de consulta no incluye el WhatsApp ni el nombre de quien crea la orden.

Acceso por enlace

El regalo no tiene contraseña: después de aprobar el pago, puede verlo quien tenga su enlace. Las fotos son accesibles mediante su URL. Esta demo está publicada en internet. Quien tenga el enlace puede abrir el regalo.

Conservación y cambios

No se configuró un vencimiento automático ni un botón para eliminar o editar regalos guardados. Cambiar el mensaje y guardarlo crea un enlace nuevo. El período de conservación se definirá antes del lanzamiento. Si necesitas ayuda con un regalo o quieres solicitar su eliminación, puedes escribir al WhatsApp 978 371 277; la página no ofrece eliminación automática.

Servicios y pagos

El pago se verifica manualmente con tu voucher por WhatsApp. No se recopilan datos de tarjetas. La tipografía se carga desde Google Fonts, por lo que el navegador realiza una conexión a ese servicio. Esta versión no incorpora herramientas de publicidad ni analítica.

Antes de subir una foto

Usa fotos que tengas permiso para compartir y evita información sensible. Se aceptan JPG, PNG y WebP de hasta 3 MB.
